# MAINSTREAM™
Premium clothing ecommerce starter.

## Files
- `index.html` — homepage
- `shop.html` — filterable collection
- `product.html` — product detail page
- `style.css` — styling and responsive layout
- `script.js` — cart, product rendering and interactions
- `assets/` — brand assets

## GitHub Pages
Upload the contents to a repository, then enable **Settings → Pages → Deploy from branch → main / root**.

Replace the placeholder product visuals with your real product photos when ready.
